# Coaching C3.4 - MNIST CNN Accuracy Improvement

---

## Learning Objectives
By the end of this session, students will be able to:
- Identify key techniques for improving CNN performance on MNIST
- Implement progressive improvements from basic CNN to state-of-the-art methods
- Collaborate effectively in teams to solve computer vision challenges
- Present technical findings to peers with clear explanations

---

## Session Overview
**Duration:** 3 hours  
**Baseline:** MLP with ~97% accuracy  
**Target:** Achieve 99%+ accuracy using CNN improvements  
**Format:** Team-based implementation and presentations

---

## Session Outline

### Phase 1: Brainstorming (30 minutes)
- **Introduction (5 min):** Problem setup, baseline results, available tools
- **Team Brainstorming (25 min):** Identify improvement strategies and select challenges

### Phase 2: Implementation (2 hours) 
- **Coding Session (120 min):** Implement chosen techniques. Instructors will drop in during session

### Phase 3: Presentations (30 minutes)
- **Team Presentations (3-4 min each):** Present implementation, results, and learnings
- **Discussion:** Compare approaches and accuracy achievements

---

## Required Materials
- Choose the most powerful machiens in the team to run higher epoch, larger datasets
- Starter notebook (to be provided)
